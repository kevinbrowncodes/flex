# App Store screenshots

Everything here is regenerated by `scripts/screenshots.sh` — never edit the PNGs by hand.

| Folder | What |
|---|---|
| `raw/iphone`, `raw/ipad` | Device-pixel captures from the simulator (iPhone 6.9" 1320×2868, iPad 13" 2064×2752) |
| `shots.json` | Captions, theme and layout for the `shotkit` compositor |
| `out/<device>/NN-<id>.png` | The files to upload to App Store Connect, in order |
| `raw/watch`, `out-watch` | Apple Watch Series 11 (46mm) captures, 416×496, uploaded as captured (no frame or caption; `shotkit` knows no watch device, so they stay out of `out/`). `scripts/gates/watch-screenshots.sh` checks them |

## How a capture is produced

The app has a DEBUG-only launch hook (`Support/DemoMode.swift`):

| Variable | Effect |
|---|---|
| `FLEX_DEMO=sample` | In-memory store with the sample library, templates, folders and 8 weeks of generated history; signed in; welcome dismissed |
| `FLEX_DEMO=empty` | In-memory store with only the bundled exercise library |
| `FLEX_THEME=Dark` | Forces the theme without touching UserDefaults |
| `FLEX_TAB=workout` | Initial tab (`profile`, `history`, `exercises`, `workout`) |
| `FLEX_USER_NAME=Ashton` | Display name (Ashton is the demo lifter everywhere, STORY_013) |
| `FLEX_DEMO_WATCH=128` | Pretends a watch is linked at that heart rate, so the active workout shows "♥ 128" and "On watch" (STORY_013) |

`FlexUITests/ScreenshotTests.swift` launches with those variables, drives the UI to each
state and writes `XCUIScreen.main.screenshot()` to `FLEX_SCREENSHOT_DIR`
(passed by `xcodebuild` as `TEST_RUNNER_FLEX_SCREENSHOT_DIR`). The status bar is set
to 9:41 / full battery with `simctl status_bar` before the run.

| Raw file | App state |
|---|---|
| `00-watch-hero` | HEAVY DUTY PUSH 41 minutes in, first bench set done, rest counting, the watch linked (`FLEX_DEMO_WATCH=128`); shot 1 |
| `01-templates` | Workout tab, "Heavy Duty" folder expanded |
| `02-active-workout` | HEAVY DUTY PUSH started from its template, first bench set completed |
| `03-plate-calculator` | Second bench set weight → keypad → plate calculator |
| `04-history` | History tab |
| `05-profile` | Profile tab (dashboard charts) |
| `06-summary` | "Great Job!" screen after finishing the push workout |
| `07-calendar` | History → calendar sheet (captured, not currently in `shots.json`) |
| `08-exercises` | Exercises tab |

Watch (`raw/watch`, `FlexWatchUITests/WatchScreenshotTests`): `01-home` the templates and this week's count, `02-logging` Set 1 of 2 of Heavy Push, `03-rest` the countdown after Done, `04-finished` the finished screen.

## Regenerate

```bash
scripts/screenshots.sh              # capture both devices, render, contact sheet, verify
scripts/screenshots.sh --render-only  # after editing shots.json
scripts/screenshots.sh --watch-only   # just the Apple Watch set
IPHONE_SIM="iPhone 17 Pro Max" IPAD_SIM="iPad Pro 13-inch (M5)" scripts/screenshots.sh
```

Requires the `appstore-screenshot-kit` checkout next to this repo (or `KIT=/path`).
